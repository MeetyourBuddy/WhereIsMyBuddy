# Where is my buddy? 🤝

A community-driven platform that connects like-minded individuals for collaboration, learning, and growth. Find your perfect study buddy, project collaborator, or mentor in your field of interest.

## Features 🌟

- User profiles with skills, interests, and learning goals
- Match-making system based on shared interests and goals
- Real-time chat and collaboration tools
- Project activities creation and management
- Skill-based search and filtering

## Tech Stack 💻

- [Vite](https://vitejs.dev/) - Next Generation Frontend Tooling
- [React](https://reactjs.org/) - UI Library
- [TypeScript](https://www.typescriptlang.org/) - Type Safety
- [Shadcn UI](https://ui.shadcn.com/) - Component Library
- [Tailwind CSS](https://tailwindcss.com/) - Styling
- [Tanstack Query](https://tanstack.com/query) - Data Fetching
- [Zustand](https://zustand-demo.pmnd.rs/) - State Management

## Prerequisites 📋

- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)

## Getting Started 🚀

### Installation

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```
